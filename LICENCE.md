## 🧩 About

**Cronos The New Dawn Companion** is a curated list of Cronos The New Dawn open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD viewer, waypoint switcher
- **Quality-of-Life Helpers** — inventory catalog, loadout manager, overlay notes
- **Research Notes** — encounter layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Encounter Helpers
- Waypoint Switcher — practice from any checkpoint
- HUD Viewer — visualize resource and threat indicators
- Replay Notes — record and review encounter runs
- Playback Speed — adjust practice playback for study (0.1x to 5x)

### 🎨 Catalog & Loadouts
- Item Catalog — browse gear, upgrades, trails, effects
- Custom Loadout Notes — organize character builds
- Threat overlay — improved awareness layout for study

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Movement Tuning Notes — study traversal on complex terrain
- Combo Buffer Notes — chain complex maneuvers in the editor
